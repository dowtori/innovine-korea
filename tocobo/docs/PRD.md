**문서 버전:** 1.0  
**작성일:** 2026-05-18  
**담당:** SIRIAI

---

## 1. 개요

### 1.1 배경

TOCOBO는 비타민 선케어 라인을 중심으로 한 K-뷰티 브랜드로, 깨끗하고 현대적인 브랜드 정체성을 가진다. 이번 팝업 이벤트 "IN MY SUN ERA"는 LECT 성수 1F에서 진행되며, 팔로워 조건 없이 제품 체험에 진심인 크리에이터를 모집한다.

SIRIAI가 집행하는 이번 모집 페이지는 TOCOBO의 브랜드 톤앤매너를 충실히 반영하면서, SIRIAI 기존 작업물(oddtype-invite, influencer-5man)에서 검증된 UX 패턴을 적용한다.

### 1.2 목표

- 팝업 기간(5/18~5/24) 중 방문 가능한 크리에이터를 온라인으로 모집
- 모집 정보를 Google Sheets에 자동 수집 (Google Apps Script 연동)
- TOCOBO 브랜드 이미지와 일치하는 고품질 랜딩 경험 제공

### 1.3 성공 기준

- 페이지 로딩 후 5초 이내 주요 정보 파악 가능
- 폼 제출 완료율 (랜딩 진입 대비 폼 submit) 목표: 60% 이상
- 모바일 환경(375px~) 에서 이탈 없는 완전한 사용성

## 4. 페이지 구조

### 4.1 전체 흐름

```
[랜딩 섹션] ──→ CTA 클릭 ──→ [폼 섹션]
                                   ↓
                              Step 1: 기본 정보
                                   ↓
                              Step 2: SNS 계정
                                   ↓
                              Step 3: 방문 일정
                                   ↓
                              [완료 화면]
```

### 4.2 랜딩 섹션 콘텐츠 구조

1. **헤더 로고** — TOCOBO 워드마크 (텍스트 또는 이미지)
2. **히어로 타이틀** — "IN MY SUN ERA"
3. **서브 카피** — "태양을 더 자유롭게 즐기는 시간 / TOCOBO 팝업에 초대합니다"
4. **이벤트 정보 카드** — 기간, 장소, 대상 (아이콘 + 텍스트 3열)
5. **혜택 섹션** — 키트 이미지(tocobogift.jpg) + 구성 목록
6. **유의사항** — 간결한 불릿 리스트
7. **CTA 버튼** — "지금 신청하기" (화면 하단 고정 또는 섹션 내 배치)

### 4.3 폼 섹션 구조

| Step | 필드 | 유효성 |
|------|------|--------|
| Step 1 | 이름 (text), 전화번호 (tel) | 필수, 010-XXXX-XXXX 형식 |
| Step 2 | 인스타그램 링크 (url) | 필수, URL 또는 @계정명 |
| Step 3 | 방문 가능일자 (checkbox × 7), 주/야간 선호 (radio × 3), 개인정보 동의 (checkbox) | 날짜 1개 이상 필수, 동의 필수 |

**방문 가능일자 선택지 (7개 카드, 2열 그리드)**
- 5/18(월), 5/19(화), 5/20(수), 5/21(목), 5/22(금), 5/23(토), 5/24(일)

**주/야간 선호 선택지 (3개 라디오)**
- 주간 선호, 야간 선호, 상관없음

## 5. 데이터 수집

### 5.1 Google Apps Script 연동

- **방식:** fetch POST → Google Apps Script Web App URL
- **시트:** Google Sheets 자동 기록
- **stub 패턴:** endpoint = null 시 콘솔 출력만, 성공 화면 정상 표시 (테스트 모드)

### 5.2 POST 페이로드

```json
{
  "campaign": "TOCOBO × SIRIAI IN MY SUN ERA 2026",
  "name": "홍길동",
  "phone": "010-1234-5678",
  "sns_link": "https://www.instagram.com/example/",
  "visit_dates": "5/20(수), 5/21(목)",
  "time_pref": "주간 선호",
  "agr_optional": "동의",
  "timestamp": "2026-05-18T10:30:00+09:00"
}
```

> "위 정보는 TOCOBO × SIRIAI 팝업 모집 목적으로만 수집·이용되며, 행사 종료 후 파기됩니다."

## 6. 기능 요건

| 기능 | 우선순위 | 설명 |
|------|----------|------|
| 멀티스텝 폼 | P0 | 3단계 + 완료화면, 뒤로가기 지원 |
| 클라이언트 유효성 검사 | P0 | 각 step 진행 전 필드 검사, 에러 메시지 인라인 표시 |
| 진행률 표시 | P0 | 상단 진행 바 (3단계 기준 1/2/3 스텝 표시) |
| Apps Script POST | P0 | 비동기 제출, 로딩 스피너, 성공/실패 분기 |
| stub 모드 | P0 | EP = null 시 콘솔 로그 + 성공화면 (배포 전 테스트용) |
| 모바일 반응형 | P0 | 375px~ 완전 지원 |
| 랜딩 ↔ 폼 전환 | P1 | CTA 클릭 → 폼 표시, 폼 내 뒤로가기 → 랜딩 복귀 |
| 완료 화면 | P1 | 신청 완료 메시지 + 인스타 계정 팔로우 유도 (선택) |

## 7. 비기능 요건

- **단일 파일:** `index.html` — CSS, JS 인라인 포함 (번들러 없음)
- **외부 의존:** Google Fonts (Instrument Sans, Noto Sans KR) CDN만 허용
- **접근성:** 모든 인터랙티브 요소 aria-label, aria-required 적용
- **코드 품질:** 비압축, 읽기 가능한 클래스명, CSS 변수 활용
- **브라우저:** Chrome/Safari/Firefox 최신 버전, 모바일 웹뷰
